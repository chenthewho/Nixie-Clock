# Nixie-Clock

> 辉灯管时钟，跑在区块链上

单文件、零依赖、零图片：`index.html` 用 Canvas 2D 逐像素还原参考图里的霓虹管时钟。

直接用浏览器打开即可：

```bash
open index.html          # 或双击文件
```

## 这是什么

画面是一排 6 只霓虹管（nixie tube）+ 2 个分隔灯，上面一行日期。
`index.html` 不引用任何外部资源，玻璃罩、阳极蜂窝网、灯丝辉光、底座、分隔灯
全部由代码在运行时绘制。

## URL 参数

| 参数 | 作用 | 例子 |
| --- | --- | --- |
| `t` | 固定时间（默认跟随系统实时走时） | `?t=23:08:36` |
| `d` | 固定日期 | `?d=10/10` |
| `w` | 固定星期 | `?w=SATURDAY` |
| `static` | 关闭全部动画，便于逐像素比对 | `?static=1` |

例：`index.html?t=23:08:36&d=10/10&w=SATURDAY&static=1` 即为参考图的定格状态。

## 实现要点

- **设计空间固定 2507 × 1343**（与参考图同尺寸），运行时等比缩放居中；
  所有几何常量都是对参考图逐像素测量得到的。
- **玻璃灯罩**：轮廓不是手画的贝塞尔，而是把参考图的肩部/颈部按 **每 4px 实测**列成
  `GLASS.profile`（颈部小球的平直段、锥面、肩部外扩、直筒段、圆角底），逐点连成路径；
  左内壁亮线按实测定位在 `cx-126`、峰值 ≈106，外沿保持全黑，内腔再按“上亮下暗”加竖向压暗。
  颈部锥面另加一道镜面高光（实测 y=435 处 x≈cx-20、亮度 113）。
- **蜂窝极板**：板面 = 金属框 + 内嵌网孔区。左右压条、上下压条各有独立渐变
  （左峰 126 / 右峰 103 / 上下条 50~80，均取自实测）；网孔为圆角方孔（孔距 10.2px、
  孔径 0.62 倍、孔缘 2.6px 模糊），发光之后再叠加辉光，于是亮处被自然填平、暗处保留网纹。
  铆钉是暗橄榄色小圆盘 + 细环，尺寸按实测 29px。
- **金属底座**：参考图里它不是圆角方块，而是 **一整块 260×66 的暗板**，中央一道暗缝、
  左右各一个亮区、边缘向外渐隐。这里直接用实测的 34 个横向取样点做成渐变，肉眼几乎无法区分。
- **字形**：每个数字的笔画中心线由参考图峰值法提取（实测六个数字高度都 ≈300px，
  其中 "2" 的斜画起点、"3" 的中腰转折、"8" 的腰身、"6" 的茎部都按骨架点重建），
  再用 Catmull-Rom 转三次贝塞尔平滑；启动时量出路径包围盒，按实测宽高与中心精确映射。
- **辉光**：灯丝是一条窄笔芯，外扩柔光由“同一笔芯的逐级模糊副本”用 `lighter` 叠加。
  早期版本用「更宽的实色描边」打底，会在亮芯外留一圈暗环（看着像空心管），已改掉。
- **起辉动画**：数字变化时先随机跳字抖动约 60% 时长，再“过亮”落定，平时有轻微呼吸与偶发闪断。

## 可调参数

文件顶部集中了所有可调项：

- `GLASS` / `TUBE_CX` / `SEP_CX`：玻璃外形、六只管与分隔灯的位置
- `MESH` / `holePat`：蜂窝网的孔距、孔径、孔缘柔度与压暗强度
- `GLYPH_DEF` / `GLYPH_TARGET`：数字的笔形路径与实测目标尺寸
- `drawGlow()` 里的 `passes`：辉光每一档的模糊半径与加法贡献（决定芯部亮度与光晕衰减）
- `drawDate()`：日期文本的字号、压缩系数与斜杠画法
